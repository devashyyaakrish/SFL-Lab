# Internal implementation contracts

Use Python package `sfl_lab`. Config models in `config.py` are the canonical contract, authored by the lead agent. Return JSON-safe dictionaries (no NaN/Infinity; use null plus explanatory status). Accuracy is percent 0–100; absolute accuracy differences are percentage points. Times in seconds, bytes in bytes, energy in joules.

## Owned modules and interfaces

* `engine.py`, `models.py`, `datasets.py`: `run_training(config: ExperimentConfig, variant: str, seed: int, progress=None, cancelled=None) -> dict`. variant baseline/candidate. progress accepts a dict. Cancelled callable returns bool. Return `history` (per round: round, train_accuracy, train_loss, val_accuracy, val_loss, epsilon, communication_bytes, runtime_seconds), `metrics` (test_accuracy, test_loss, val_accuracy, val_loss, train_accuracy, train_loss, runtime_seconds, communication_bytes, energy_joules, epsilon, drift_mean, fairness_std), `clients` (id,samples,accuracy,loss,drift), `communication` (activation,intermediate,gradient_back,gradient_front,synchronization bytes), `compliance` (list of {name,status,detail}), `privacy` (accountant info), `dataset` (split counts,partition,split hashes), `environment`, `stopped_early`, `split`. Test only final checkpoint selected on validation. No fabricated metrics. Engine calls formula and science contracts below. Expose small `build_model(model_name,num_classes,split)` returning U-shaped model with `.front`, `.middle`, `.back` modules. Datasets expose `prepare_data(config,seed)` object with train/val/test tensors and client index lists (coordinate names with science agent).
* `formulas.py`: `catalog() -> dict` of hooks, templates, operations, keyboard. `validate_candidate(candidate: CandidateConfig) -> dict` with `valid`, `checks` [{name,status,detail}], normalized expression, formula_info. `apply_hook(candidate, hook: str, context: dict) -> Any`, returns appropriate tensor/scalar/list or None if hook inactive. Never arbitrary eval. Tensor hooks H1/H2 use A, H3 Z, H5/H6 G; H4 loss; H7 eta; H8 weights n/N; H9 rho; H10 split selection score; H11 S/R/(1-p)+d; H12 energy; H13 scores; H14 regularizer. Algorithm mode maps supported protections to H2/H6 and controlled required stages; reject semantically unsupported constructs.
* `science.py`: `RDPAccountant(delta, epsilon_max=10, warning_fraction=.8)`, `.record(clip:float, sigma:float, count:int=1, mechanism:str='gradient')`, `.epsilon` property float|None, `.summary() -> dict`. Conservative Gaussian sensitivity=2C (replace-one), no amplification, counts all releases; epsilon only for transcript NOT full system/model DP. `network_cost(byte_counts:dict, config:NetworkConfig, seed:int=0) -> dict` total latency in `total_seconds`; `energy_cost(compute_seconds:float, network:dict, config:EnergyConfig) -> dict` energy in `total_joules`. Attack function `run_attacks(config, progress=None, cancelled=None) -> dict`, actual optimization and clearly scoped assumptions. Dynamic profile utility if time available.
* `analysis.py`, `reports.py`, `suites.py`: `compare_runs(baseline:list[dict],candidate:list[dict],config) -> dict` with baseline/candidate aggregates, deltas, statistics, hypothesis_status, recommendation, criteria, limitations, pareto. `run_suites(config, base_runs, candidate_runs, progress=None,cancelled=None) -> dict` actual runs via engine; preserve test isolation in sweep/selection and label exploratory tests. `make_report(experiment:dict,format:str)-> bytes` for json/csv/pdf/markdown. Plot data from results only.
* `api.py`, `storage.py`, CLI and integration: lead agent.
* `frontend/`: React TypeScript Vite dashboard agent.

## API (lead implements)
GET `/api/health` → {status,version}; GET `/api/catalog` → formula catalog plus defaults: ExperimentConfig JSON; GET `/api/experiments` → list of experiment records; POST `/api/validate` body CandidateConfig → validation; POST `/api/experiments` body {config: ExperimentConfig, action:'full'|'compare'|'baseline'|'candidate'} → record. Record `{id,name,status,phase,progress,config,created_at,updated_at,error,result,logs}`. GET `/api/experiments/{id}` → record; POST `/api/experiments/{id}/cancel`; GET `/api/experiments/{id}/export?format=json|csv|pdf|markdown` download. Status queued/running/completed/failed/cancelled. Poll 1–2s. result `{baseline:run[],candidate:run[],comparison:dict,suites:dict,validation:dict,limitations:list,environment:dict}`. Frontend should show unrun results honestly, no mock metrics. API root serves built frontend. Default frontend Vite :5173 proxies /api to backend :8000; installed production app backend :8000.

Scientific limits: local single-process simulation preserves logical client boundaries, not OS or cryptographic isolation; actual tensor messages/gradients must be detached at both cuts. Baseline is fixed sample-weighted FedAvg reference, architecture inspired by OS-USFL, never claim original numerical reproduction without original paper settings/data. Network/energy are model estimates, accuracy/runtime/bytes are measured. Server counts mean simulated replica assignment and synchronization, not real distributed speedup. Any unsupported/unrun feature must be explicitly labeled, never fake a pass.
